# Testing Sprint 4 - Digitalización SGH

## Objetivo
Validar el correcto funcionamiento del módulo de digitalización del sistema hospitalario SGH, incluyendo carga de documentos, asociaciones automáticas, validaciones y consistencia de datos.

---

## Alcance
Se validarán:

- endpoints de tipos de documento,
- carga de documentos,
- filtros y búsquedas,
- validaciones de datos,
- integridad referencial,
- asociaciones entre documentos y personas,
- estabilidad post-merge.

---

## Herramientas utilizadas

- Postman
- MySQL Workbench
- Git
- Jira
- VS Code
