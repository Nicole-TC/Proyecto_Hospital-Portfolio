Módulo de Digitalización

Guía para el usuario

1. ¿Cómo acceder?

Ingresá a la página del sistema con tu usuario y contraseña. En el menú de la izquierda buscá la sección Digitalización. Ahí vas a ver las siguientes opciones:

Subir Documento

Subí un archivo (PDF o imagen) al sistema. Escribí el DNI de la persona y el sistema la busca automáticamente en la base de datos.

¿Qué puedo hacer?

  • Subir archivos nuevos en formato PDF, JPG o PNG.
  • Asignarle un tipo de documento, servicio y etiquetas.
  • Agregar un título y una descripción al archivo.

Etiquetas

Las etiquetas sirven para organizar y clasificar los documentos. Por ejemplo: "Urgente", "Auditoría", "Facturado".

¿Qué puedo hacer?

  • Crear una etiqueta nueva con nombre y color.
  • Editar el nombre o color de una etiqueta existente.
  • Desactivar una etiqueta si ya no se usa (no se borra, solo se oculta).
  • Activar una etiqueta que estaba desactivada.

Tipos de Documento

Son las categorías de archivos que se pueden subir: Historia Clínica, Receta, Informe, etc.

¿Qué puedo hacer?

  • Crear un tipo de documento nuevo.
  • Editar el nombre de un tipo existente.
  • Desactivar un tipo que ya no se usa (no se borra del todo para mantener el historial).
  • Activar un tipo que estaba desactivado.

Buscar Documento

Buscá documentos usando diferentes filtros como DNI, etiqueta, servicio o rango de fechas.

¿Qué puedo hacer?

  • Ver el archivo completo haciendo clic en "Ver".
  • Editar los datos del documento (título, persona, tipo, servicio, etiquetas).
  • Borrar un documento (se desactiva, no se elimina del todo. Si lo borraste por error, podés recuperarlo desde la Papelera).

Auditoría

Es un historial de todo lo que se hizo en el sistema: quién subió, modificó o borró algo, con fecha y hora.

¿Qué puedo hacer?

  • Consultar las acciones filtrando por tipo (subidos, modificados, eliminados), tabla o fecha.
  • Ver el detalle de cada acción haciendo clic en el ojo. Se muestra qué campo cambió y cuál era el valor antes y después.
  • No se puede modificar ni borrar nada. Es solo de lectura.

Servicios

Son los sectores del hospital: Pediatría, Guardia, Cardiología, etc. Cada servicio tiene un responsable asignado.

¿Qué puedo hacer?

  • Crear un servicio nuevo con nombre, área y responsable.
  • Editar el nombre, área, responsable o estado de un servicio.
  • Desactivar un servicio que ya no se usa (queda inhabilitado pero no se borra).

Configuraciones Solo administradores

Son las opciones generales del sistema de digitalización. Solo los administradores pueden modificarlas.

¿Qué puedo hacer?

  • Editar el valor de cada configuración (por ejemplo: cambiar el tamaño máximo de archivo o los formatos aceptados).
  • No se pueden crear ni borrar configuraciones. Solo se modifican los valores.

Papelera Solo administradores

Acá van a parar los documentos que se "borraron" desde la búsqueda. No se eliminan del todo, quedan guardados por si los necesitás.

¿Qué puedo hacer?

  • Ver el archivo completo haciendo clic en "Ver".
  • Restaurar un documento para que vuelva a aparecer en las búsquedas normales.
  • Eliminar definitivamente un documento. Esto borra el archivo del servidor y no se puede recuperar.

2. Seguridad y Validaciones

El módulo cuenta con una doble capa de seguridad tanto en el Frontend (JavaScript y Atributos HTML) como en el Backend (PHP).

  • Archivos: Solo se admiten formatos .pdf, .jpg, .png (configurable desde Configuraciones). El límite de peso también es configurable.
  • Bases de Datos: Independencia total. Digitalización solo lee y escribe en PostgreSQL ($bd_dig).
  • Permisos: Cada sección tiene control de acceso por sesión: dig_nuevo_documento, dig_admin_etiquetas, dig_tipos_documentos, dig_buscar_documentos, dig_auditoria, dig_servicios. Configuraciones y Papelera son exclusivos de administradores.
