Módulo de Digitalización

Manual de Usuario y Configuración Técnica

1. ¿Cómo usar el Módulo?

Una vez que el proyecto esté corriendo en la VPS (accediendo a través de http://149.50.137.127:8080/admin), podrás encontrar la sección "Digitalización" en el menú lateral izquierdo (Sidebar). Este menú ofrece accesos rápidos a las 4 funciones principales:

Nuevo Documento

Permite subir un archivo PDF o imagen. El sistema buscará automáticamente a la persona por su DNI en la base de datos.

Administrar Etiquetas

Abre el panel CRUD para gestionar los "Tags" de los documentos. Útiles para clasificar los archivos (Ej: Urgente, Auditoría, Facturado).

Tipos de Documentos

CRUD flotante (Modal) para gestionar los tipos principales de archivos (Historia Clínica, Receta, Informe). Usa tecnología de Soft-Delete para no romper el historial.

Buscar Documento

Motor de búsqueda para encontrar documentos históricos por filtros DNI, Etiqueta, Servicio, estado del archivo o tipo de archivo. (Módulo en expansión).

2. Seguridad y Validaciones

El módulo cuenta con una doble capa de seguridad tanto en el Frontend (JavaScript y Atributos HTML) como en el Backend (PHP).

  • Archivos: Solo se admiten formatos .pdf, .jpg, .png con un tamaño máximo de 5000 Bytes.
  • Bases de Datos: Independencia total. Digitalización solo lee y escribe en PostgreSQL ($bd_dig).
