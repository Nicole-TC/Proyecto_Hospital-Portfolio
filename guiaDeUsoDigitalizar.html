Módulo de Digitalización

Manual de Usuario y Configuración Técnica

1. Entorno y Configuración (Docker)

Este módulo ha sido diseñado para funcionar de manera completamente aislada mediante contenedores de Docker, utilizando una base de datos PostgreSQL exclusiva para garantizar el rendimiento en la carga masiva de archivos.

Variables de Entorno (.env)

Para que el sistema se conecte correctamente a la base de datos de digitalización y despliegue el servidor, debes asegurarte de que tu archivo .env en la raíz del proyecto contenga las siguientes variables obligatorias:

APP_PORT=8050
DB_DIG_HOST=149.50.133.15
DB_DIG_USER=dev_dig
DB_DIG_PASSWORD=d3v_d1g!
DB_DIG_NAME=digitalizar
DB_DIG_PORT=9432
Nota: Los archivos subidos por los usuarios se almacenarán dentro del contenedor de Docker en un volumen local (/admin/uploads/digitalizar/).

2. ¿Cómo usar el Módulo?

Una vez que el proyecto esté corriendo en la VPS (accediendo a través de http://149.50.137.127:5337/admin), podrás encontrar la sección "Digitalización" en el menú lateral izquierdo (Sidebar). Este menú ofrece accesos rápidos a las 4 funciones principales:

Nuevo Documento

Permite subir un archivo PDF o imagen. El sistema buscará automáticamente a la persona por su DNI en la base de datos. Posee validación estricta de 8 dígitos para DNI y topes de tamaño.

Administrar Etiquetas

Abre el panel CRUD para gestionar los "Tags" de los documentos. Útiles para clasificar los archivos (Ej: Urgente, Auditoría, Facturado).

Tipos de Documentos

CRUD flotante (Modal) para gestionar los tipos principales de archivos (Historia Clínica, Receta, Informe). Usa tecnología de Soft-Delete para no romper el historial.

Buscar Documento

Motor de búsqueda para encontrar documentos históricos por DNI, Etiqueta, o tipo de archivo. (Módulo en expansión).

3. Seguridad y Validaciones

El módulo cuenta con una doble capa de seguridad tanto en el Frontend (JavaScript y Atributos HTML) como en el Backend (PHP).

  • Archivos: Solo se admiten formatos .pdf, .jpg, .png con un tamaño máximo de 5MB.
  • DNI: Forzado a 8 dígitos exactos. No permite letras ni caracteres especiales.
  • Fechas: Bloqueo de fechas futuras mediante JavaScript.
  • Bases de Datos: Independencia total. Digitalización solo lee y escribe en PostgreSQL ($bd_dig).
