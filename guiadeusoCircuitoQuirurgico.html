Módulo de Circuito Quirúrgico

Manual de Usuario y Configuración Técnica

1. ¿Cómo usar el Módulo?

Una vez que el proyecto esté corriendo en la VPS (accediendo a través de http://149.50.137.127:8080/admin), podrás encontrar la sección "Circuito Quirúrgico". Este menú ofrece accesos a 7 módulos principales:

Dashboard

Métricas y Monitoreo en tiempo real del Circuito Quirúrgico.

Admisión de Pacientes

Formularios para la carga de pacientes al circuito.

Seguimiento

Control de asistencia del paciente a su cita para los estudios prequirúrgicos.

Lista de Espera

Lista de Espera Quirúrgica de los pacientes.

Agenda de Turnos

Agenda para programar los diferentes tipos de turnos.

Usuarios

Administración de usuarios y permisos del sistema.

Auditoría Global

Historial de actividades del sistema.

2. Seguridad y Validaciones

El módulo cuenta con una doble capa de seguridad tanto en el Frontend (JavaScript y Atributos HTML) como en el Backend (PHP).

  • Admision de pacientes: Primero se pide el DNI para evitar que se complete datos de un usuario que ya está registrado, si está registrado se trae automáticamente,en el caso que no esté se habilita el formulario para completar los campos restantes.
  • Gestion de usuarios: Se pide el DNI pero si existe se bloquea todo el formulario hasta que ingrese uno que no exista
